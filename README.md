# Diplom_3

 В проекте тестируем  элементы, которые будем использовать в тестах, с помощью Page Object, 
 функциональность в Google Chrome и Яндекс Браузере

Перечень тестируемых классов:

Регистрация
    Успешная регистрация
    Ошибка для некорректного пароля

Вход
    вход по кнопке «Войти в аккаунт» на главной
    вход через кнопку «Личный кабинет»
    вход через кнопку в форме регистрации
    вход через кнопку в форме восстановления пароля

Раздел «Конструктор»
    «Булки»
    «Соусы»
    «Начинки»
